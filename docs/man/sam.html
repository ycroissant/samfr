Social Account Matrix

Description

Generate a SAM for France, many arguments enable the user to customize the result

Usage

## S3 method for class 'sam'
summary(object, ...)

## S3 method for class 'sam'
as.matrix(x, ...)

sam(
  an = NULL,
  naf = c("A17", "A38", "A1", "A4", "A10", "Sections"),
  tot_gen = TRUE,
  isbl = FALSE,
  sep_ent = FALSE,
  net_acc = TRUE,
  net_tax = TRUE,
  net_cap = TRUE,
  rev_int = FALSE,
  simpl_dist = FALSE,
  trace = FALSE,
  unit = c("G", "M", "K", "PIB")
)

Arguments

object, x an object of class sam,
… further arguments for the summary and the as.matrix method (currently unused)
an a year
naf, isbl, net_acc, sep_ent, net_tax, simpl_dist, net_cap see stbl
tot_gen a boolean, if TRUE, a general total is added for each account
rev_int a boolean, if TRUE, intermediary incomes (primary income and disposable income are added to the SAM)
trace a boolean, if TRUE (the default is FALSE), some information messages are printed while computing the SAM
unit monetary unit, K for thousands of euros, M for millions of euros, G for billions of euros (the default) and PIB for a 100 base for the PIB,

Details

sam returns a data frame in long format (one line for each value), with a “sam” class. The as.matrix method transforms the SAM in a large format, each row and column being an account.

Value

an object of class mcs which inherits the data.frame class
